picoGym: the RSA set and more

picoGymJune 2026

picoGym is picoCTF’s archive of past challenges. I worked through every RSA challenge in it as cryptography practice for UBC’s CTF team.

The RSA set

Each one breaks RSA because of how it was used, not the math itself. The attacks I used:

  1. 01Wiener's attack

    Small d

    When the private exponent is small, it falls out of the continued-fraction expansion of e/N.

  2. 02Pollard's p − 1

    Smooth p − 1

    If p − 1 has only small prime factors, a^(k!) − 1 shares the factor p with N.

  3. 03RSA-CRT

    Leaked CRT values

    The CRT exponents dp/dq let you recover a prime factor and rebuild the key.

  4. 04Chosen ciphertext

    Unpadded RSA

    Textbook RSA is multiplicative: decrypt c·2^e instead of c, then divide by 2.

  5. 05Weak modulus

    ClusterRSA

    The modulus was already factored in factordb, so the private key is one modular inverse away.

Other solves

  • Custom Encryption: a Diffie-Hellman exchange over p = 97, then a reversed XOR with a fixed key and multiplication by key · 311. The challenge prints both secret exponents, so the shared key can be recomputed directly. After that you divide each value back out and undo the XOR.
  • MyGit: the server only accepts a flag commit pushed as root <root@picoctf>. Git takes the author identity from local config, so setting that name and email is enough.

Tools: Python · PyCryptodome · factordb
