## Headings & text

Use `##` for section headings and `###` for subsections (the title above is the
only `#`/h1). Inline you get **bold**, _italic_, `inline code`, and
[links](https://testoupr.github.io). Separate paragraphs with a blank line.

> Blockquotes use a leading `>`. Good for pull-quotes or noting an assumption.

## Lists

- Bullet lists use `-`
- Nest by indenting two spaces
  - like this
1. Numbered lists use `1.` `2.` …
2. …and render in order

## Code

Fenced blocks get syntax highlighting (Shiki, light/dark aware). Put the
language after the opening fence:

```python
def cooccurrence(matrix):
    # keyword co-occurrence = D^T D
    return matrix.T @ matrix
```

## Math

Inline math with single dollars: the leakage is a vector $a \in \{0,1\}^n$.
Display math with double dollars on their own lines:

$$
\mathrm{Co}(D) = D^\top D, \qquad D \in \{0,1\}^{n \times m}.
$$
