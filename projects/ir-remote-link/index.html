Infrared Remote-Control Link

CompleteClass projectMarch 2026

15+ m

reliable range, with virtually no dropped commands in testing

The infrared link that remote-controls a robot car, written in embedded C on an STM32.

  • Physical layer: serial bytes at 500 baud, switched onto a 38 kHz carrier generated by a hardware timer.
  • Protocol: a start byte, then a 2-byte frame (command + value).
  • Receiver: interrupt-driven decoding that switches the robot between manual driving and automatic path-following.

Stack: Embedded C · STM32 · hardware timers · interrupts
