# Trip photos — drop zone

Upload your travel images here. Name each file after the city, optionally
followed by a few words about the shot:

- `lisbon-old-town-tram.jpg`
- `tokyo shibuya crossing.png`
- `vancouver.jpg`

Spaces, hyphens, any case, and .jpg/.jpeg/.png/.webp all work. Multiple
photos of the same city are fine — they'll be grouped into one trip post.

Claude sorts these into `public/trips/<city>/`, picks a cover, looks up
coordinates, and drops a pin on the travel map. This folder can be emptied
once that's done.
