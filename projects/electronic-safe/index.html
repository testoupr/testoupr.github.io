Electronic Safe on FPGA

CompleteClass project · 1 weekOctober 2025

A combination-lock controller for an electronic safe, designed in SystemVerilog and run on an FPGA.

  • Control: a 4-state machine (lock, verify, alarm, reset) with keypad scanning kept in separate logic.
  • Input safety: the keypad is asynchronous, so every input goes through multi-flop synchronizers and debouncing to avoid metastability.
  • Verification: self-checking testbenches that exercise every state transition, then bring-up and debugging on the board.

Stack: SystemVerilog · FPGA · simulation testbenches
