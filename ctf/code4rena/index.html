Code4rena audit contests

Code4renaApril 2025

Code4rena runs public audit contests: a protocol publishes its code, and wardens compete to find vulnerabilities before it ships.

From April 2025 to May 2026 I reviewed production Solidity codebases, including Chainlink and Flare. It’s the same skill set as Ethernaut (reentrancy, access control, unsafe external calls), applied to real code with real money behind it.
