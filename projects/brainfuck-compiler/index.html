Brainfuck Interpreter in 8051 Assembly

CompleteClass projectFebruary 2025GitHub ↗

A Brainfuck interpreter in 8051 assembly that runs directly on a microcontroller. No keyboard: you type, edit and run programs with four push buttons on a 16×2 LCD.

  • All 8 commands, including nested loops: on [ it scans ahead to the matching ] and replays the loop until the cell is zero.
  • Input with , pauses the program and lets you enter a digit with the same buttons.
  • The hard part: the 8051’s stack grows up, and calls to far-away subroutines need long jumps.
