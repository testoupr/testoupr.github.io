sid stops every program launch on a Linux machine at the kernel until a local model gives a verdict: allow, block, or hold. Held commands run in a throwaway copy of the filesystem so a person can see what they would have changed before deciding.

My part

  • Designed and built the entire Hold path, end to end: simulating held commands in an overlay sandbox, a filesystem diff that catches every created, modified and deleted file, the human review queue, and containment that kills whatever launched a blocked command.
  • Defined the daemon’s contract with the decision model: exactly what context the model sees (command, user, origin, parent chain, recent history) and the verdict and probabilities it returns, so the model could be trained separately and dropped in.
  • Integrated the system: merged the fine-tuned model and command-review work, wired the dashboard to the daemon’s review socket, and surfaced the model’s probabilities to reviewers.
  • Built the test suite for command review, overlay edge cases and crashed commands.
  • Shipped it: the Docker demo environment with GPU passthrough, the one-line curl | sh installer, and the README.
