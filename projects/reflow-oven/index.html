Reflow-Oven Controller

CompleteTeam of 6 · class projectJanuary 2026

A controller that drives a toaster-style oven through a solder reflow profile, written in 8051 assembly. My parts were the control state machine and the keyboard interface.

%%{init: {"flowchart": {"rankSpacing": 24, "nodeSpacing": 20}}}%%
flowchart LR
  A[ready] --> B[ramp to soak] --> C[soak] --> D[ramp to reflow] --> E[reflow] --> F[cooling]
  B -.->|not 50 °C after 60 s| X([abort: heater off])
  • Control: a 6-state machine that sets heater power for each phase through a 102 Hz PWM output.
  • Safety abort: if the oven hasn’t reached 50 °C within 60 s of starting, it cuts the heater. That catches a disconnected thermocouple or a dead heater.
  • Keyboard interface: a second FPGA board with an interrupt-driven PS/2 driver and 7 single-key commands to set and read back all 4 reflow parameters, with input validation. It talks to the oven over GPIO, so you can change profiles without reflashing the firmware.

Stack: 8051 assembly · PS/2 · PWM · GPIO
